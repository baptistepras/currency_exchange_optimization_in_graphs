# Projet-Optimisation-Finances-M1

Javier Peña Colada, Martin Leivasion Fiscale, et Autiste Pras

Ce git rend compte du projet Finance. Il est composé du rendu écrit (réponses aux questions 1 à 6) dans `Projet_Optimisation_Finances.pdf`, du code dans `opty.py` et des slides pour la présentation dans `slides.pdf`.

Nous avons fait 4 codes:
1) Algorithme naïf et inefficace
2) Algorithme inspiré de Bellman-Ford, beaucoup plus efficace
3) Mélange de l'algorithme 2 avec le problème du unbounded knapsack
4) Utilisation dynamique des algorithmes 2 et 3 pour minimiser le temps d'exécution
